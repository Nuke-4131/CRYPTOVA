How CRYPTOVA works

A structured workflow designed for security and auditability

1

Upload & classify

Select a file and assign a sensitivity classification (Public, Internal, Confidential, Restricted). CRYPTOVA records file metadata before any operation begins.

2

Configure protection

Choose an encryption algorithm and key derivation settings. CRYPTOVA generates an authenticated package including an HMAC integrity signature bound to the file content and metadata.

3

Authenticate before decrypt

Every decryption request passes through a five-stage verification pipeline. Packages that fail integrity checks are blocked immediately — the decrypted content is never accessed.

4

Auditable activity log

Every encryption, decryption, and verification event is recorded with a timestamp, actor, target file, and outcome. Full audit trail for compliance reporting.
